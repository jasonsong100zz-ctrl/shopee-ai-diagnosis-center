# FM 虾皮竞品监控新人 SOP

版本：V1.2
复核日期：2026-08-24
适用对象：第一次使用 FM 虾皮竞品监控 Skill 和 Chrome 扩展的业务同事
默认方式：人工启动、已登录 Chrome、离线采集、下载 UTF-8 CSV

## 1. 这套工具做什么

本工具根据 Google Sheet 或 CSV 中已经提供的 Shopee 竞品链接，逐个打开商品页并生成一次采集快照。它适合固定竞品清单的每日追踪，不负责自动找新品、关键词排名或店铺后台数据。

每个识别到的 SKU 单独占一行。商品级字段会在同一商品的每个 SKU 行重复，便于后续在 Excel、Google Sheets 或 BigQuery 中筛选和比较。

采集必须使用符合平台规则的、已登录的人工浏览器环境。遇到登录、CAPTCHA、滑块或流量验证时，工具会暂停，由人工在可见浏览器中完成验证后再继续。

## 2. 首次使用前准备

新人开始前确认以下条件：

- 已安装 Google Chrome，并能正常打开目标 Shopee 市场，例如 `shopee.co.id`。
- 已在当前 Chrome 用户配置中登录 Shopee；不要把密码、Cookie 或导出的登录信息交给工具。
- 已拿到 FM Skill 压缩包 `fm-shopee-competitor-monitor.zip`，或由管理员把 Skill 安装到本机。
- 已拿到竞品清单 Google Sheet 链接，并确认该表可被扩展读取。

建议使用固定的 Chrome 用户配置文件。不要在采集过程中切换 Chrome 账号、退出 Shopee、清理站点数据或关闭扩展。

## 3. 安装 FM Skill

这一步通常只做一次。

### Windows 安装

1. 解压 `fm-shopee-competitor-monitor.zip`。
2. 将解压后的完整文件夹 `fm-shopee-competitor-monitor` 复制到：

   `%USERPROFILE%\.codex\skills\fm-shopee-competitor-monitor`

3. 确认文件夹内直接能看到 `SKILL.md`，不要多套一层同名文件夹。
4. 重启或刷新 Codex。
5. 在 Codex 中输入 `$fm-shopee-competitor-monitor`，确认 Skill 可以被调用。

如果团队管理员已经完成安装，新人不需要重复安装 Skill，只需确认能调用它即可。不要把个人 Token、Google 服务账号 JSON 或 BigQuery 私钥复制进 Skill 文件夹。

## 4. 安装 FM Chrome 扩展

这一步通常只做一次；扩展更新后需要重新加载。Skill 不能绕过 Chrome 安全限制静默安装未签名的本地扩展，但可以自动准备扩展目录并打开安装页面。

1. 在已登录 Shopee 的目标 Chrome 中运行 Skill 内置脚本：

   `powershell -ExecutionPolicy Bypass -File scripts/install-chrome-extension.ps1`

2. 脚本会把扩展复制到稳定目录，并打开 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择脚本输出的目录；不要选择 Skill 文件夹或 ZIP 文件。
5. 在扩展列表中确认名称为“FM 竞品监控”，并将扩展固定到 Chrome 工具栏。
6. 如果是更新扩展，在 `chrome://extensions` 点击该扩展的刷新按钮，再重新打开弹窗。

扩展只使用当前浏览器页面和页面正常返回的数据，不读取或导出 Chrome 密码、Cookie。扩展目录不要移动或删除，否则 Chrome 会提示扩展路径失效。

## 5. 准备竞品清单

### 必填表头

Google Sheet 的首行应包含以下四列，名称必须完全一致：

| 表头 | 填写内容 |
| --- | --- |
| `品类` | 业务品类，例如 Setting Spray |
| `产品` | 内部使用的产品名称或类型 |
| `竞对品牌` | 竞品品牌 |
| `竞品链接` | Shopee 商品详情页链接 |

每一行放一个商品链接。链接应是商品详情页，并包含类似 `-i.695661253.23834605586` 的店铺 ID 和商品 ID。不要把店铺首页、搜索页或短链放进清单。

### 可选列

可以增加 `market`、`enabled`、`priority`、`target_model`、`tracking_frequency` 和 `notes`。

- `enabled` 填 `false`、`0`、`no`、`否` 或 `停用` 的行不会采集。
- 暂时不追踪某个商品时，优先将 `enabled` 设为 `否`，不要删除历史记录。
- 其他可选列不会替代四个必填列。

### 分享权限

扩展读取的是 Google Sheet 的 CSV 导出内容。开始前请确认链接可以访问并允许查看；最稳妥的做法是将表格设置为“知道链接的用户可查看”，或按团队权限开放可导出访问。不要把包含不相关敏感信息的工作表一起开放。

扩展会根据链接中的 `gid` 读取对应工作表。若链接没有 `gid`，默认读取第一个工作表。

## 6. 首次配置扩展

1. 点击同一个已登录 Chrome 工具栏中的 FM 图标；不要改用 Codex 内置浏览器。
2. 在“竞品清单链接”粘贴 Google Sheet 编辑链接或 CSV 导出链接。
3. “保存方式”选择“离线采集并下载 CSV（推荐）”。
4. “下载后云端同步”选择“不同步（仅保存本地 CSV）”。
5. 第一次先不要填写“本地发布桥地址”和“工作区 UUID”；离线模式不需要本地服务监听。
6. 关闭并重新打开弹窗，确认链接和模式仍然保留。

设置会保存在当前 Chrome 的扩展本地存储中，换电脑、换 Chrome 用户配置或清除扩展数据后需要重新配置。账号密码仍由 Chrome/Shopee 自己管理，FM 不保存密码。

## 7. 每日采集操作

每天按以下顺序执行：

1. 打开已经登录 Shopee 的目标 Chrome 用户配置，确认 FM 扩展已启用。
2. 打开 FM 扩展弹窗，检查竞品清单链接和“离线采集”设置。
3. 点击“开始监控”。
4. 等待扩展读取清单。状态会先显示类似“已读取 N 条链接”。
5. 采集期间不要反复点击“开始监控”、不要关闭正在使用的 Shopee 标签页，也不要手动连续切换 SKU。
6. 如果页面出现验证，按第 8 节处理；如果没有验证，等待进度继续变化。
7. 任务完成后点击“下载本次结果 CSV”。
8. 在 Chrome 保存窗口选择团队规定的目录，并保留默认文件名，例如 `FM竞品监控-2026-08-24.csv`。

扩展会自动等待页面加载并观察商品页的正常数据。它不会为了补齐价格而自动逐个点击 SKU；因此某些页面只能确认当前 SKU 时，应以 CSV 中的价格状态为准，不要把空值手工猜成价格。

## 8. 如何判断已完成

满足以下任一组合即可确认本次任务已经结束：

- 弹窗状态以“监控完成”开头，例如“监控完成：成功 20 条”。
- 若有失败链接，状态会显示成功数和失败数，例如“监控完成：成功 18 条，失败 2 条”。
- 扩展图标角标显示绿色 `✓`。
- 弹窗出现“下载本次结果 CSV”按钮可点击，并显示“下载位置：Chrome 下载目录/FM竞品监控-日期.csv”。

点击下载后，扩展会显示“下载已发起”。实际文件位置以 Chrome 的下载记录为准，可打开 `chrome://downloads`，在对应文件上选择“在文件夹中显示”。云端同步失败不会删除本地 CSV。

## 9. 验证、暂停和继续

### 遇到 CAPTCHA、滑块或流量验证

1. 看到验证页面后不要反复点击“开始监控”，也不要尝试脚本破解。
2. 在当前可见 Shopee 页面中按平台提示人工完成登录或验证。
3. 确认页面已经回到商品页，且商品内容正常显示。
4. 打开 FM 弹窗，确认状态为“已暂停”。
5. 点击“验证后继续”。

扩展图标出现橙色 `!` 代表需要人工处理。不能通过拖动轨迹模拟、验证码识别、代理轮换、隐藏浏览器或提高请求频率来规避平台验证。

### 页面跳转、未登录或打不开

先处理当前页面的登录、跳转或网络问题，再点击“验证后继续”。如果任务没有暂停而只是部分链接失败，等任务结束后点击“重试失败”。

## 10. CSV 结果验收

打开下载的 CSV 后，先检查以下内容，再交付或同步：

- 每个识别到的 SKU 是独立一行；同一商品可能因此有多行。
- `商品ID`、`店铺ID`、`SKU ID` 用于匹配历史数据，不要只按商品标题匹配。
- `SKU价格状态=已确认` 才表示该 SKU 价格已从可验证页面数据中获得。
- `需选择确认` 表示识别到 SKU，但页面没有提供该 SKU 的完整价格；不能当作 0。
- `未识别 SKU` 表示没有拿到模型列表，需要人工复核商品页或记录为采集质量问题。
- `最低SKU价格` 和 `最高SKU价格` 只有在所有识别到的 SKU 价格都已确认时才可信；为空不代表商品没有价格。
- `当前价格` 只代表当时页面当前选中的 SKU 或页面显示价格，不等于全部 SKU 的价格区间。
- `采集状态` 和 `失败原因` 必须保留，不能为了报表美观删除失败行。

常见业务字段包括：商品标题、当前价格、原价、折扣率、币种、库存状态、累计已售代理值、评分、评论数、促销摘要、优惠券和配送摘要。累计已售是页面可见的代理指标，不等同于真实订单、GMV、流量或库存。

## 11. 失败重试规则

### 任务完成但有失败链接

1. 先查看弹窗中的“失败链接”及失败原因。
2. 能人工修复的先修复：重新登录、打开正常网络、处理页面验证或检查链接。
3. 点击“重试失败”。
4. 重试完成后重新点击“下载本次结果 CSV”。
5. 若仍失败，保留失败原因并按第 14 节模板上报，不要连续无限重试。

### 清单读取失败

优先检查：Google Sheet 是否可查看、链接是否完整、首行表头是否正确、`竞品链接` 是否为商品详情页。修正后重新点击“开始监控”。

### 任务卡住

等待页面完成加载后再观察一次；不要同时开多个采集任务。若状态长时间不变化，记录当前商品、Chrome 页面和弹窗状态，点击“停止”，修复问题后重新执行。

## 12. 可选：个人云端同步

离线 CSV 是默认交付物，云端同步不是采集成功的前提。只有管理员提供了个人或团队批准的 HTTPS Webhook 后，才按以下步骤配置：

1. 在弹窗将“下载后云端同步”改为“同步到我的接口”。
2. 填写个人同步接口地址，例如 `https://your-domain.example/upload`。
3. 填写接口 Key / Token。
4. 点击“授权此接口”，确认状态变为“接口已授权”。
5. 先执行一次小范围测试，确认本地 CSV 能下载且接口能收到 `report_rows`。

每个人应使用自己的接口地址或 Token，不要共享个人 Token。公网接口必须是 HTTPS；本地 HTTP 只允许 `localhost` 或 `127.0.0.1`。任务完成时先发起本地 CSV 下载，再尝试云端同步；弹窗会显示“同步成功”或“同步失败”。

不要把 Token 写入 Google Sheet、Skill、扩展压缩包、截图、自动化提示词或 Git 仓库。若 Token 泄露，立即在服务端撤销并重新生成。

## 13. 每日完成检查清单

完成后逐项勾选：

- [ ] 使用的是正确的 Chrome 用户配置，Shopee 登录状态正常。
- [ ] 采集清单链接和日期正确，没有误用测试表。
- [ ] 弹窗状态以“监控完成”开头。
- [ ] 已下载本次 CSV，并能在 `chrome://downloads` 找到文件。
- [ ] 已核对成功数、失败数和失败原因。
- [ ] 已抽查至少一个多 SKU 商品，确认 SKU 是分行显示。
- [ ] 已确认最低价、最高价没有在价格不完整时被误读。
- [ ] 若启用云同步，已核对同步状态；同步失败时已保留本地 CSV。
- [ ] 已按团队命名规则归档文件，例如 `市场_日期_负责人`。

## 15. 常见问题

### Q1：新人每天需要安装 Skill 吗？

不需要。Skill 和扩展均为一次安装；每天只需打开已登录 Chrome，确认设置后手动点击“开始监控”。

### Q2：能不能完全无人值守定时抓取？

当前扩展是人工启动设计。可以配置提醒或受控的本地定时任务，但遇到登录、验证码、流量验证或页面变化必须暂停。不要保存密码或 Cookie 来强行实现无人值守。若团队后续有合规且稳定的数据源，再由管理员评估服务端定时采集。

### Q3：为什么某些 SKU 价格为空或显示需选择确认？

商品页可能只在选择 SKU 后返回价格，或页面没有完整公开模型价格。工具会保留 SKU 身份并标记质量状态，避免把当前 SKU 的价格错误复制给所有 SKU。

### Q4：为什么最低价和最高价为空？

因为并非所有识别到的 SKU 都有已确认价格。此时空值是质量保护，不是采集失败；应先查看各 SKU 行的 `SKU价格状态`。

### Q5：云端同步失败，数据会丢吗？

不会。只要点击了下载，CSV 仍保存在本地。先交付本地文件，再联系接口管理员检查 HTTPS、Token、接口权限和服务端日志。
